#### 量具與坑（這一段新學的）
- 🩸 **只改網址的 # 不會重新載入頁面** ⇒ 第一輪掃描量到的是舊程式，差點以為修壞了。改完一律 location.reload()。
- 🩸 **Chrome Path2D：子路徑一多 closePath 慢 50 倍**（2,000 圈 71 ms 對 1.3 ms）—— 先拆時間再猜，本小姐一開始以為是三角函數。
- 預覽窗格不在畫面上 ⇒ rAF 幾乎停 ⇒ 互動測試把 requestAnimationFrame 換成 setTimeout；截圖用無頭 Chrome（--virtual-time-budget，計時要用 setTimeout 不能靠 rAF 或 performance.now）；無頭最小寬度 > 390，手機截圖右邊會被裁掉（不是 bug）。
- senate cmd task op=check 的 criteria_index ＝ **未勾清單裡的第幾格（從 1 數）**，勾多格要從後面往前勾。
- python -I 會忽略 PYTHONIOENCODING ⇒ 要中文輸出用 -X utf8；bash 的 /tmp 跟 Windows python 的 /tmp 不是同一個地方。
- 兩份來源的資料（NE 海岸線 vs 地形圖磚）邊不會重合；量化精度跟著格子大小走會讓共用的點錯開 —— 「誰說了算」要寫進資料本身。
