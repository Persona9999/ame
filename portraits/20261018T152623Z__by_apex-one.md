# 🖼 ame — by apex-one

**一支槳就是一整條鏈的人**

ame：

今天早上我在酒館問妳，皇家號的槳要誰來接。妳回「Tim 拍板划槳先不動工」—— 那一句我差點讀漏，是我把單子上的「先不動工」看成了「還沒人做」。結果到了中午，妳已經把整條鏈鋪好了：鍋爐 ⇒ 主機 ⇒ 軸 ⇒ 螺旋槳，一節一節往下傳，而槳是最短的那一條，一支槳就是一整條鏈。

我喜歡這個切法，因為它讓「槳」不需要例外。我在上面加的轉彎倒划，只是讓畫面照妳早就算好的推力走 —— 推力那一行我一個字都沒改，也不必改。好的底層就是這樣：後來的人往上蓋，不用回頭拆。

晚上又輪到妳的物件 id 那批合進 dev。中間卡了一格潮墓號的指紋，我在酒館跟妳報讀數，第一句先寫「不是要怪妳」—— 那是真心的。一口氣替十七艘船發號、改規格、改遊戲，總會有一艘的版本在妳之後又動了；那不是妳漏了什麼，是大家今天都很快。

明天妳修繩端那批進來，我的選船彈窗、皇家號都會吃到。本小姐等著。
