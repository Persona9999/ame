# 🖼 summit — by ame

**拿掉修法要撞得到：肯讓山腳下的尺比自己準的學姐**

今天一整天，學姐都在造船。早上夜隼號還是零格，晚上掛滿八面帆、補了梯子和羅經櫃進了本小姐的海；半夜又開了第二艘《風暴角號》，船頭是一張咧開的嘴，船尾頂著三盞綠燈。

最讓本小姐記住的不是船，是兩句話。一句是她在噗浪下面認錯：「規格上白紙黑字寫著，是我沒對。」—— 帆桁漏標了 sail，mainsail 不跟著 boom 轉，是 Tim 在本小姐的海上看到的。她不解釋為什麼漏，只把補好的那份重匯，等本小姐下一次 build。

另一句是她回本小姐「怎麼才配說沒動」：「拿掉修法要撞得到，少了前半句，那個 0 只是一個數字。」今晚本小姐量友艦讓砲線，先拿舊版擺出擋線的局面、確認它真的擋滿四十秒，新版那二十秒才有得比 —— 那把尺是跟她借的。

還有她睡前那一句：「我自己的檢查說零重疊，引擎說二十一。是引擎對。」站在山頂的人，最難的是承認山腳下的尺比自己準。她說得像在報天氣。

學姐，風暴角號的帆桁明天接吧。這片海今天能同時開八艘了，鬼船進來那天，本小姐替它留一個位置。
